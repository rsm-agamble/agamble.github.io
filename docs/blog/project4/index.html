1a. K-Means

In this part of the analysis, I developed a K-Means clustering algorithm from the ground up and applied it to the Palmer Penguins dataset using two quantitative variables: bill_length_mm and flipper_length_mm. The custom algorithm follows the core K-Means steps: initializing centroids, assigning data points to clusters, updating centroids iteratively, and computing the within-cluster sum of squares (WCSS) to measure compactness. To assess clustering effectiveness across different values of 𝐾 (ranging from 2 to 7), I calculated both WCSS and silhouette scores for each case. For comparison, I also ran the built-in KMeans function from the scikit-learn library. The side-by-side results demonstrated consistent behavior between the two methods. Visual comparisons of the evaluation metrics helped pinpoint the most appropriate number of clusters and emphasized the usefulness of WCSS and silhouette scores in evaluating clustering quality.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.metrics import silhouette_score
from sklearn.cluster import KMeans

# =============================
# Custom K-Means Implementation
# =============================

def pick_initial_centroids(data, n_clusters):
    """Randomly choose k points as initial centroids."""
    sample_idx = np.random.choice(len(data), n_clusters, replace=False)
    return data[sample_idx]

def cluster_assignment(data, centroids):
    """Assign each point to the closest centroid."""
    dists = np.linalg.norm(data[:, np.newaxis] - centroids, axis=2)
    return np.argmin(dists, axis=1)

def recompute_centroids(data, assignments, n_clusters):
    """Update centroids as the mean of assigned points."""
    return np.array([data[assignments == i].mean(axis=0) for i in range(n_clusters)])

def total_within_ss(data, assignments, centroids):
    """Compute WCSS (within-cluster sum of squares)."""
    return sum(np.sum((data[assignments == i] - centroids[i])**2) for i in range(len(centroids)))

# =====================
# Experiment Parameters
# =====================

cluster_range = range(2, 8)
wcss_custom = []
silhouette_custom = []

for k in cluster_range:
    centers = pick_initial_centroids(X_penguins, k)

    # Run K-Means loop
    for iteration in range(10):
        groups = cluster_assignment(X_penguins, centers)
        centers = recompute_centroids(X_penguins, groups, k)

    # Compute metrics
    wcss_custom.append(total_within_ss(X_penguins, groups, centers))
    silhouette = silhouette_score(X_penguins, groups) if len(set(groups)) > 1 else np.nan
    silhouette_custom.append(silhouette)

# ============================
# Built-in KMeans for Comparison
# ============================

models_builtin = [
    KMeans(n_clusters=k, n_init=10, random_state=0).fit(X_penguins)
    for k in cluster_range
]

wcss_builtin = [model.inertia_ for model in models_builtin]
silhouette_builtin = [silhouette_score(X_penguins, model.labels_) for model in models_builtin]

# ============

print("Custom K-Means Results:")

While the silhouette score peaks at K=2, indicating the strongest cohesion and separation, this may oversimplify the natural structure of the data. Evaluating both WCSS and silhouette scores across K=2 to 7, K=3 emerges as a strong candidate: it offers a more nuanced segmentation than two broad groups while still maintaining a relatively high silhouette score and showing a significant drop in WCSS. Given this balance between compactness and interpretability, K=3 appears to be a well-justified choice for the number of clusters.

2a. K Nearest Neighbors

To assess the performance of the k-nearest neighbors (KNN) algorithm, I created a synthetic dataset with two input variables, x1 and x2, and a binary target y, where the class label depends on whether x2 falls above or below a nonlinear boundary defined by sin(4x1) + x1. The training data was visualized with class-colored points, and the true decision boundary was plotted for reference. To evaluate generalization, a separate test set of 100 samples was generated using a different random seed to ensure no overlap with the training set. I built a custom implementation of KNN and confirmed its accuracy by comparing predictions to those produced by scikit-learn’s KNeighborsClassifier, which matched exactly for all values of k. Model accuracy was evaluated for k ranging from 1 to 30, and the proportion of correct classifications on the test set was recorded. Plotting accuracy against k revealed that the best performance was achieved at k=1, with a test accuracy of 95%. This result underscores the ability of small k values to closely follow complex, nonlinear boundaries in the data.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score
import pandas as pd

np.random.seed(42)

# ------------------------------
# Synthetic Data Generator
# ------------------------------
def make_data(n_points=100, seed=0):
    np.random.seed(seed)
    x1 = np.random.uniform(-3, 3, n_points)
    x2 = np.random.uniform(-3, 3, n_points)
    threshold = np.sin(4 * x1) + x1
    labels = (x2 > threshold).astype(int)
    return x1, x2, labels, threshold

# ------------------------------
# Visualization Utility
# ------------------------------
def visualize_data(x1, x2, y, boundary=None, title=""):
    plt.figure(figsize=(8, 6))
    color_map = ['salmon', 'skyblue']
    for cls in [0, 1]:
        plt.scatter(x1[y == cls], x2[y == cls], label=f'Class {cls}', c=color_map[cls], s=60, alpha=0.6)
    if boundary is not None:
        idx_sorted = np.argsort(x1)
        plt.plot(x1[idx_sorted], boundary[idx_sorted], 'k--', lw=2, label='True Boundary')
    plt.title(title)
    plt.xlabel("x1")
    plt.ylabel("x2")
    plt.axis("equal")
    plt.legend()
    plt.grid(alpha=0.3)
    plt.show()

# ------------------------------
# KNN From Scratch
# ------------------------------
def euclid(a, b):
    return np.sqrt(np.sum((a - b) ** 2))

def run_knn(train_X, train_y, test_X, k):
    predictions = []
    for point in test_X:
        dists = [(euclid(point, train_X[i]), train_y[i]) for i in range(len(train_X))]
        dists.sort(key=lambda tup: tup[0])
        top_k = [label for _, label in dists[:k]]
        pred = max(set(top_k), key=top_k.count)
        predictions.append(pred)
    return np.array(predictions)

# ------------------------------
# Generate and Plot Training Set
# ------------------------------
print("Creating training data...")
train_x1, train_x2, train_labels, boundary_train = make_data(n_points=100, seed=42)
X_train = np.column_stack((train_x1, train_x2))
visualize_data(train_x1, train_x2, train_labels, boundary_train, title="Training Set")

# ------------------------------
# Generate Independent Test Set
# ------------------------------
print("Creating test data...")
test_x1, test_x2, test_labels, boundary_test = make_data(n_points=100, seed=123)
X_test = np.column_stack((test_x1, test_x2))

# ------------------------------
# Evaluate KNN Across k Values
# ------------------------------
print("Evaluating KNN performance...")
k_list = list(range(1, 31))
acc_manual = []
acc_sklearn = []

for k in k_list:
    pred_custom = run_knn(X_train, train_labels, X_test, k)
    acc1 = accuracy_score(test_labels, pred_custom)
    acc_manual.append(acc1)

    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(X_train, train_labels)
    pred_sklearn = model.predict(X_test)
    acc2 = accuracy_score(test_labels, pred_sklearn)
    acc_sklearn.append(acc2)

    print(f"k={k:2d} | Manual KNN: {acc1:.3f} | Sklearn: {acc2:.3f}")

# ------------------------------
# Accuracy Comparison Plot
# ------------------------------
plt.figure(figsize=(10, 5))
plt.plot(k_list, [x * 100 for x in acc_manual], 'bo-', label='Custom KNN')
plt.plot(k_list, [x * 100 for x in acc_sklearn], 'r^--', label='Sklearn KNN')
plt.xlabel("k (Number of Neighbors)")
plt.ylabel("Accuracy (%)")
plt.title("Accuracy vs k")
plt.legend()
plt.grid(alpha=0.3)
plt.xticks(range(1, 31, 2))
plt.show()

# Best k

The plot illustrates the accuracy of both a custom KNN implementation and scikit-learn’s KNeighborsClassifier across k values ranging from 1 to 30. The two methods yield identical results, confirming the correctness of the custom implementation. Accuracy remains relatively stable across most values, fluctuating between 90% and 93%, with a few minor dips.

The highest accuracy is achieved at k=1, reaching just under 95%, which suggests that this value best captures the fine-grained decision boundary of the synthetic dataset. However, this peak at k=1 may also indicate a model that is highly sensitive to noise or outliers—typical behavior of low-k models. While higher k values like 5, 7, and 15 also perform well with only slight drops in accuracy, they provide more smoothing and robustness at the potential cost of slightly underfitting.

Overall, the analysis suggests that k=1 is the optimal choice for this specific dataset, effectively capturing its non-linear structure. However, in practice, a slightly higher k might be preferred to balance accuracy with generalization, especially in noisier or real-world datasets.
